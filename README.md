AI Battle Arena

Welcome to **AI Battle Arena**, where multiple AI models compete to deliver the best possible answer.

When a user submits a prompt or question, the **same prompt is sent simultaneously to two different AI models**. Both models generate their responses independently, creating a fair head-to-head comparison.

To determine which response is more accurate, relevant, and helpful, a **third AI model acts as an unbiased judge**. It evaluates both answers based on the user's prompt and selects the better one.

The interesting part? **Users never know which AI model generated which response.** This ensures that every answer is judged purely on its quality, without any bias toward a particular model.

### AI Models Used

* **Gemini**
* **Mistral AI**
* **Cohere AI** (Judge)

The goal of AI Battle Arena is simple: **let the best answer win.**
